## Новый квест

Шесть этапов: цель и сущности, граница системы, модель связей, порядок операций, правила интервалов и проверка сценариями. На выходе проект JSON и объяснение. Баллы вычисляет сервер; смысл свободного текста проверяет преподаватель.

Создавая группу в пульте, выбери тип «Логическое проектирование программы». Приглашение автоматически ведёт в /logic/. Пульт обновляет результаты каждые три секунды. Самостоятельный режим без кода хранится только в браузере и позволяет скачать самоотчёт. Интернет нужен для первоначальной загрузки и группового режима.

Прежние группы, состояния и код 7VKYHLHW относятся к VM-практике и сохранены. Отдельная новая тестовая группа по проектированию: **HBKHZQE3**. Старые ссылки главной с ?code=... перенаправляются в VM-квест для совместимости.

## Материалы

Текущие презентация, приглашение и план относятся к логическому проектированию. Старые материалы сохранены с префиксом materials/vm-. В приглашении сохранены согласованные данные открытого урока; количество студентов не публикуется.

## Сервер

В vm_rooms добавлено поле quest (vm / logic), старым группам присвоено vm. Состояние нового проекта имеет kind=logic, сервер выбирает соответствующий reducer. Проверка типа при входе предотвращает смешение заданий. Все таблицы закрыты RLS от прямого браузерного доступа; секрет преподавателя и студенческие токены не публикуются.

## Проверки

`node tests/logic.cjs` — этапы, граничные случаи, защита баллов, сброс и одинаковые клиентский/серверный движки. Браузерная проверка выполняет все шесть этапов, сохраняет и скачивает проект. Реальный API проверяется отдельно; временные тестовые данные удаляются после проверки.
