# VM Quest

Визуальная практика по виртуализации: сборка компьютера, распределение ресурсов между двумя VM, изоляция отказов и восстановление. Это учебная модель в браузере.

- [Задание](https://zholdaskali.github.io/vm-quest/)
- [Пульт преподавателя](https://zholdaskali.github.io/vm-quest/teacher.html)
- [Шпаргалка с GIF](https://zholdaskali.github.io/vm-guide/)

Студент вводит ник и код группы из приглашения. Без кода доступна самостоятельная работа с JSON-отчётом. Преподаватель входит с личным секретом, создаёт группу и отправляет ссылку студентам. Результаты обновляются каждые 3 секунды через Supabase; баллы вычисляются сервером.

Секрет преподавателя, токены и пароли не добавлять в репозиторий. Настройки функции описаны в backend/ПОДКЛЮЧЕНИЕ.txt. Для GitHub Pages: Deploy from a branch → main → / (root).

В пульте нажми «Показать QR для студентов»: экран для проектора содержит приглашение в выбранную группу, код и счётчик участников. Доступны полноэкранный режим, копирование ссылки и скачивание QR в SVG. QR генерируется локально; секрет преподавателя в приглашение не входит.
